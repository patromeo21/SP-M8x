# SP-M8x A1.1 — Implementation Manifest

## Scope
A1.1 introduces the serializable project-domain types, a complete initial project factory, and a pure migration boundary for the currently shipped in-memory app data.

## Files added
- `src/project/projectTypes.ts`
- `src/project/initialProject.ts`
- `src/project/migrateLegacyProject.ts`
- `src/project/index.ts`

## Compatibility and safety
- Existing application files are not replaced or edited.
- Existing `Pad`, `TrackerPattern`, `PunchInFXState`, `MasterFXState`, `BankId`, `SamplerMode`, and `ThemeMode` types are reused.
- `AudioBuffer` is not stored in the project document. Migration records decoded audio metadata only; binary sample persistence and runtime cache registration are later A1 stages.
- Existing 16 pads migrate to Bank A; Banks B–D remain empty.
- The old generic tracker command/value pair is preserved in the Phrase FX fields without assigning unverified semantics.
- Song scaffolding is initialized as eight tracks by 32 empty rows.
- Existing FX settings can be passed into the migration function. If omitted, defaults match the currently inspected `FxStrip` state.

## Deliberately not included
- No App.tsx integration.
- No UI changes.
- No audio-engine changes.
- No persistence or IndexedDB implementation.
- No transport, scheduler, or song playback behavior.

## Integration example
```ts
import { migrateLegacyProject } from './project';

const project = migrateLegacyProject({
  pads,
  pattern: trackerPattern,
  bpm: 125,
  samplerMode,
  punchInFX,
  masterFX,
});
```
